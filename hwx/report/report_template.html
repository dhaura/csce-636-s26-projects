Summary

Where the project stands

The pipeline works end to end, and a published literature baseline (Gessert et al., 2018, 2nd place in ISIC 2018) was reproduced within 0.01 of its reported score. One-factor experiments then optimised the plain ResNet-50 from 0.724 to 0.835 test balanced accuracy: correcting for class imbalance after training, 448-px input, and 20-view test-time augmentation. Swapping in stronger backbones (ConvNeXt-S, EfficientNetV2-S, ViT-B/16, DINOv2) gave no single model that beats ResNet-50 on test. Averaging the five backbones, however, was the best choice on the CV folds by a wide margin. All 25 models together reach 0.892, above the ISIC 2018 winner (0.885, external data). Every choice was made on the CV folds, never on the test set.

Task

Seven-way diagnosis from a dermoscopy image

Each input is a 600 × 450 dermoscopic photo of a skin lesion. The model outputs one of seven diagnoses: MEL melanoma, NV melanocytic nevus (mole), BCC basal cell carcinoma, AKIEC actinic keratosis / Bowen's disease, BKL benign keratosis, DF dermatofibroma and VASC vascular lesion.

Melanoma is curable when caught early and dangerous when caught late, and accurate dermoscopy reading depends on scarce expert experience. In the ISIC 2018 reader study, the top three algorithms got 25.4 of 30 cases right against 18.8 for dermatologists with over ten years of experience, though algorithms degraded more on images from unfamiliar sources.

The data is heavily imbalanced: two thirds of the training images are moles. A model that always answers NV scores 67% accuracy and is clinically useless. The official metric is therefore balanced multiclass accuracy, the mean of the seven per-class recalls. Every result here also reports accuracy, macro-F1, macro-AUC, and melanoma sensitivity and specificity.

Project goal. Find out which training choices matter most for this task (pretraining source, adaptation method, imbalance handling), measured on the official ISIC 2018 test set and compared against published results.

Data & splits

ISIC 2018 Task 3 and a leakage-free split

Training images per class

10,015 HAM10000 images. The largest class (NV, 6,705) is 58 times the smallest (DF, 115).

Why the split is grouped by lesion

HAM10000 has 10,015 images of only 7,470 distinct lesions; many lesions were photographed more than once. A random split would put near-duplicate images of one lesion on both sides and inflate validation scores. The folds are built with StratifiedGroupKFold on lesion_id: every lesion lands in exactly one fold (verified), and each fold holds ~2,003 images with the same class mix. All experiments share these folds, so per-fold comparisons are paired.

Environment & infrastructure

  • Conda env inside the project (hwx/.conda-env): Python 3.11, PyTorch 2.14.1 + CUDA 13.0, timm 1.0.30, registered as the Jupyter kernel Python (isic-hwx).
  • Pretrained weights cache on $SCRATCH, not the small home quota.
  • Runs go to one 4-GPU node through Perlmutter's interactive QOS, which started in under a minute. The shared and regular queues estimated 1 to 6 days.
  • Driver scripts put one run per GPU and queue the rest, so 10 short runs finish in about 18 minutes.

Evaluation protocol

  • Every run reports balanced accuracy, accuracy, macro-F1, macro-AUC, melanoma sensitivity and specificity, per-class recall and the confusion matrix.
  • Each run is scored on its held-out CV fold, the official validation set and the official test set.
  • Each run saves per-image probabilities in the ISIC submission format, so models can be averaged or re-thresholded later without retraining.
  • Each run keeps both the best and the last checkpoint score, to measure how much early stopping matters.

About the literature baseline

Gessert et al. (2018) placed 2nd in ISIC 2018 Task 3 (test balanced accuracy 0.856) and were the best entry using only public data. Their paper reports single-model results under lesion-grouped 5-fold CV with every hyperparameter given, and their public code fills in the rest. Our reproduction differs only in using our own folds, ImageNet mean/std normalisation and bf16 precision. It does not include their 54-model ensemble or SVM meta-learner.

Optimisation

From 0.724 to 0.835, one factor at a time

Each experiment changed one thing, ran on all five folds with the same seed, and was compared fold by fold. Choices were made on the CV folds only; the test set is reported for every variant but never used to pick one.

Path to the optimised baseline (test balanced accuracy)

test, mean of 5 fold models (whisker ± 1 SD)│CV mean, used for the choice◇average of the 5 models' predictions

Two steps carry almost all of the gain. Logit adjustment fixes the decision boundary (+0.063, 5/5 folds) and 448-px input improves the features (+0.040, 5/5). Test-time augmentation adds a little more (+0.009, 3/5 folds on test, 5/5 on CV).

Round 1b: correcting after training vs reweighting the loss

Logit adjustment predicts argmax log p(y|x) − τ·log πᵧ, where π is the training class prior (Menon et al., ICLR 2021), with τ picked on CV. Applied to the plain-CE model it beats retraining with weights (0.786 vs 0.773), and stacking both gains nothing more. So imbalance handling alone plateaus near 0.785 for a 224-px ResNet-50.

Where the gain comes from (paired over 5 folds)

Mean difference ± SD of the per-fold difference, with the number of folds that improved. Longer training and TrivialAugment did nothing on CV, so they were not kept, even though both nudged the test score up slightly.

Round 2: every variant, ranked by CV balanced accuracy

All rows are logit-adjusted. TTA-4 averages 4 flips of the center crop, and TTA-20 averages 5 crops × 4 flips. The highlighted row was selected. The CV ranking mostly carried over to the test set: the three 448-px variants are the top three on both. The exception is 384 px, which gained on CV but not on test.

Round 3 · Backbones

Stronger backbones: no single winner, a large win together

Four backbones replaced ResNet-50 in the optimised recipe: 448 px, 30 epochs, plain CE, 20-view TTA and logit adjustment. A fold-0 pilot at 224 px first picked each backbone's learning rate. Then every backbone ran on all 5 folds.

Sorted by CV score. On CV the stronger backbones edge ahead of ResNet-50, but on test the order flips and every single backbone lands at or below it. The differences are inside the fold-to-fold noise (±0.012 to 0.026). Averaging the five backbones per fold scores far above any single model on CV (0.873 vs 0.843), and the gain holds on test.

Learning-rate pilot (fold 0, 224 px)

CV balanced accuracy after logit adjustment; the bold value is the rate used. Transformers need a lower rate than ResNet's 2e-4: DINOv2 drops to 0.718 at 2e-4. Reusing ResNet's rate would have made them look far worse than they are.

Paired difference vs optimised ResNet-50

Every backbone ranks images slightly better on test (higher AUC). None turns that into higher balanced accuracy once the decision thresholds are tuned on CV. ViT-B/16 is worse on all 5 folds.

All backbones (official test, mean of 5 fold models)

Averaging across backbones

Per fold, the five backbones' adjusted probabilities are averaged and scored on that fold's CV split. Picking on CV, all five beat four-without-ViT (0.873 vs 0.871). The 25-model average then reaches 0.892 test balanced accuracy, 0.987 AUC and 0.825 melanoma sensitivity. That is above the paper's 54-model ensemble (0.856) and the ISIC 2018 winner (0.885). Different architectures make different mistakes, so averaging them cancels errors that no single model fixes.

Findings

What the results show so far

Loss weighting is the single biggest factor so far

One change, inverse-frequency class weights, raises ResNet-50 test balanced accuracy from 0.724 to 0.773 (+0.050, better on 5 of 5 folds). That matches the full Gessert recipe (0.770) with downscaled inputs and about a sixth of the training time. The paper's own ablation found a similar gain (+0.038).

Weighting shifts the decision boundary; it doesn't improve the features

Macro-AUC is unchanged (0.966 vs 0.965), so the model ranks images no better. It simply predicts minority classes more often. Accuracy falls 0.024, melanoma specificity falls 0.024, and moles misread as melanoma more than double on fold 0. Because only the boundary moves, a cheaper fix should work, and it does (next finding).

Correcting after training beats retraining with weights

Logit adjustment of the saved plain-CE predictions, with no retraining, raises test balanced accuracy to 0.786 (+0.063, 5/5 folds), above weighted training (0.773). Weighting plus adjustment gives 0.785, so imbalance handling has a ceiling for a given set of features. The selected strength (τ = 1.6) exceeds the textbook 1.0, a sign that the network's probabilities are overconfident.

Resolution is the factor that improves the features

Moving from 224 to 448 px adds +0.040 on test after adjustment (5/5 folds) and lifts held-out AUC from 0.968 to 0.979. Unlike weighting, the model ranks images better, and that requires seeing more of the lesion's fine structure. 60 epochs (−0.000 on CV) and TrivialAugment (+0.007) did not help.

Higher resolution closes the melanoma gap with the Gessert recipe

Weighted ResNet-50 at 224 px caught fewer melanomas than the Gessert reproduction (0.674 vs 0.749) at similar balanced accuracy. The guess was that Gessert's full-resolution crops were the reason. At 448 px the optimised ResNet-50 reaches 0.759, level with Gessert, while 60 epochs and stronger augmentation did not move melanoma sensitivity up. Resolution was the missing ingredient.

Averaging fold models is a cheap, large gain

Averaging the five fold models' probabilities adds 0.042 to 0.053 balanced accuracy over the single-model mean for the ResNet-50 runs. The five optimised fold models together reach 0.870, above the paper's 54-model ensemble (0.856) and below only the ISIC winner (0.885), which used external data.

Scores drop from cross-validation to the test set

The Gessert reproduction scores 0.805 in CV but 0.770 on the test set. The ISIC 2018 reader study (Tschandl et al., 2019) notes that the test set includes images from sources absent from training, so part of this gap is likely distribution shift.

A stronger backbone alone did not help on test

ConvNeXt-S, EfficientNetV2-S, DINOv2 and ViT-B/16 all reached slightly higher test AUC than ResNet-50 (+0.001 to +0.005). None reached higher test balanced accuracy (−0.002 to −0.032). ConvNeXt-S led on CV (0.843 vs 0.831) but fell behind on test (0.817 vs 0.835). With ±0.02 fold noise, the honest reading is that at 448 px with this recipe the backbone barely matters for a single model.

Mixing architectures is the largest gain since resolution

Averaging the five backbones lifts CV balanced accuracy from 0.843 (best single) to 0.873, and the full 25-model average reaches 0.892 on test with 0.825 melanoma sensitivity. The models' individual scores are similar but their errors differ, which is exactly when ensembles pay off.

Selecting the best epoch adds little

The best and last checkpoints scored within 0.042 of each other on the held-out fold (within 0.025 for the Gessert runs). Best epochs varied widely (4 to 23 of 30 for ResNet-50), so model selection on a fold of ~2,000 images is itself noisy.

Caveats

Things to keep in mind when reading the numbers

Correction to an earlier report

The notebook baseline (one run on fold 0) scored 0.769 on the test set, and an earlier summary called it a tie with the Gessert model. Re-running the identical configuration through the script gave 0.743. GPU training here isn't bit-for-bit repeatable (cuDNN kernel choice, bf16 arithmetic, data-loader ordering), and that alone moves test balanced accuracy by about 0.025. The fair estimate for the baseline is the 5-fold mean, 0.724 ± 0.012, so the Gessert reproduction is about 0.05 better. Every comparison on this page now uses fold means and paired fold differences.

The official validation set is too small

It has 193 images, with 1 dermatofibroma and 3 vascular lesions, so one image swings a class recall by 33–100%. That is why scores on it swing widely, from 0.68 for the notebook baseline to 0.87–0.91 for the Gessert folds. It is reported but never used for conclusions.

One seed per configuration

Each configuration was trained once per fold. Fold-to-fold spread (±0.011 to 0.012) is used as the noise estimate. Differences smaller than about 0.02 should be treated as ties until more seeds are run.

CV scores after adjustment are slightly optimistic

The adjustment strength τ and the best epoch are both chosen on the same held-out fold, so adjusted CV numbers lean optimistic. The test set stays untouched, and the adjusted runs' CV and test scores agree closely (0.787 vs 0.786 for plain CE + adjustment; 0.831 vs 0.835 for the optimised model).

CV and test can disagree

The CV folds come from HAM10000. The test set has a different class mix (NV 67% → 60%, DF 1.1% → 2.9%, BKL 11% → 14%) and includes images from other sources. Round 3 showed CV rankings of near-equal models reversing on test. Only clear CV gains (resolution, ensembling) carried over reliably.

Next steps

Planned experiments, in order

  1. Medical pretraining. BiomedCLIP vs the general backbones (zero-shot, linear probe, full fine-tuning), and whether it adds diversity to the ensemble.
  2. More seeds for the single-backbone comparison, so differences under 0.02 can be called.
  3. Thresholds under shift. Higher AUC did not turn into higher balanced accuracy, so check calibration and whether the adjustment strength tuned on CV transfers to the test distribution.
  4. Figures for the slides. Grad-CAM heatmaps, a gallery of missed melanomas and common confusions, and reliability diagrams.
