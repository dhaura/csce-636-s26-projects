# Project 1 Jupyter setup

This folder provides a quick Jupyter Notebook setup for deep learning development.

## Quick start

1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start Jupyter from this folder:
   ```bash
   jupyter lab
   ```
4. Open `project1_starter.ipynb` and begin iterating on your model.
